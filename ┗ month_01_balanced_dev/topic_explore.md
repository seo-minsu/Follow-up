# Project 01 — 균형발전 정책 담론 변화 분석

## 1. 연구 배경
- 정부의 균형발전 정책은 2019~2024년 사이 정치·경제적 이슈에 따라 프레이밍이 어떻게 달라졌는지 분석의 필요성 존재
- 텍스트 데이터 기반 담론 변화 탐색 → CSS 기본 역량을 보여주는 프로젝트

## 2. 데이터 출처
- 정책브리핑 보도자료
- 기획재정부 보도자료
- 국토교통부 보도자료

## 3. 연구 질문(초안)
1) “균형발전”이라는 단어가 어떤 맥락에서 가장 많이 등장하는가?  
2) 연도별 핵심 키워드는 무엇이 달라졌는가?  
3) 어떤 부처가 담론 변화를 주도하는가?

## 4. 분석 절차 계획(초안)
- 데이터 수집 및 정리
- 형태소 분석(KoNLPy)
- TF-IDF 기반 핵심어 추출
- 워드클라우드 생성
- 연도별 키워드 변화 시각화

## 5. 기대 산출물
- summary 리포트
- keyword trend graph
- 워드클라우드 이미지
- GitHub 폴더 구조 정리
